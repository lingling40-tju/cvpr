# Sequence-level policy-loss pilots (n=4)

Three sequence aggregation objectives were tested from the same Qwen2.5-VL-3B navigation SFT initialization: GSPO-style sequence likelihood, GMPO-style geometric-mean likelihood, and arithmetic token/sequence averaging. The fixed setup used 512 fit rows, batch 8, group size 4, configured seed 11, learning rate 1e-6, reference KL 0.1, and 64 optimizer updates including the two-step smoke. All three 64-step audits show nonzero actor gradients on every update. Reward remained the same weighted success+nDTW reward; no semantic process reward was used.

On the reused development256 screen (8 R2R-train scenes), the FP16 SFT reference succeeded on 109/256 episodes. GSPO, GMPO, and arithmetic averaging succeeded on 53, 34, and 46 episodes. Paired SR/SPL changes versus SFT were -21.88/-20.56, -29.30/-27.98, and -24.61/-23.29 percentage points. Each method’s scene-bootstrap intervals are below zero for both metrics, and all failed the frozen +2/+2 pp scale gate. No scale-up followed. These single-configured-seed results on adaptively reused scenes do not establish generalization or prove which component caused the decline.

All four models had exact coverage of the 256 frozen IDs and zero inference errors. The remote raw-stat verifier passed after checking 1,024 internal evaluator IDs. `verify_local.py` independently recounts the three compact paired exports, checks source and evaluation identities, validates the training audits, and compares its metrics with both the analyzer and raw-ID report. Run `python3 verify_local.py` from this directory. The archive contains compact episode metrics and the raw-stat SHA inventory, not the full Habitat shard files.
