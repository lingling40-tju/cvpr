# Excluded 64-step training attempt (2026-09-30 to 2026-10-01 UTC)

The first three-seed training attempt must **not** be used as an RL result. Its launcher set `actor_rollout_ref.rollout.seed` to a fixed value for each run. ActiveVLN copied that value into vLLM `SamplingParams` for every request. Each pair of identical prompts in a GRPO group therefore produced identical trajectories and returns. Across the completed seed-11 and seed-22 control and event runs, all 256 episode groups per arm had duplicate generated responses and zero within-group return variance. The console logs reported `actor/grad_norm:0.000`; the first 10 MB of corresponding final actor weight shards matched, and all 512 paired rollouts per seed had the same actions. These checkpoints did not test reward-based policy learning.

The incomplete seed-33 control run and four completed runs were stopped. Their logs and checkpoints were preserved on `wanghaozhihuoshanyun` under `runlogs/eventtrace_r2r64_invalid_seeded_sampling_20261001/` and `verl_checkpoints/invalid_seeded_sampling_20261001/` rather than mixed with the corrected experiments. No full val-unseen evaluation was run from these invalid checkpoints.

`implementation/independent_group_sampling.patch` removes the per-request seed from the agent's sampling parameters while retaining a run-level vLLM engine seed. `check_grpo_preflight.py` rejects a smoke run without distinct group trajectories, nonzero within-group reward variance, and a nonzero actor gradient. The earlier two-step pilot used no per-request sampling seed and reported nonzero gradient norms; this error is specific to the larger suite launcher.
